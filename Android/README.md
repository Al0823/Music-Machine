# A.t.A. Music Player Android project


Android Studio project wrapping A.t.A. Music Player v1.2.3 in Android WebView.

- Minimum Android: 10 (API 29)
- Target/compile SDK: 35
- App ID: `com.ata.musicplayer`
- Version: 1.2.3
- Multi-file audio picker is configured through Android's document picker.

## Build an APK
1. Install Android Studio (and Android SDK Platform 35).
2. Open this folder (`ATA_MusicPlayer_Android`) in Android Studio.
3. Allow Gradle sync to complete.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

This starter project is prepared for APK packaging
